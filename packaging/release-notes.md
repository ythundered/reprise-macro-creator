download the file for your system and open it. nothing else to install.

**windows:** run the `.exe`. it isn't code signed, so windows may warn you the first time. choose more info, then run anyway.

**linux (hyprland):** make the file executable and run it. it adds itself to your app menu, and asks once for your password to get keyboard and mouse access.

```sh
chmod +x reprise-macro-creator-linux-x86_64
./reprise-macro-creator-linux-x86_64
```

see the [readme](https://github.com/ythundered/reprise-macro-creator#readme) for how to use it.
